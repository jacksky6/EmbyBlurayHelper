各平台路径参考 Windows / DSM / Docker / Linux / macOS

优先使用「从 Emby 获取」读取服务器的实际原版路径。以下为常见位置，安装方式和版本不同可能有所变化。

Windows
%APPDATA%\Emby-Server\system\ffprobe.exe便携版：Emby 解压目录下的 ffprobe.exe。%APPDATA% 为安装 Emby 的用户目录，填写时需展开为完整路径。

Docker
使用 Emby 容器内的实际路径，例如 /bin/ffprobe 或 LinuxServer 镜像的 /app/emby/bin/ffprobe。不同镜像位置可能不同。若本工具在另一容器或宿主机运行，该路径通常不能直接使用；需要共享可执行文件和配套依赖，并保证运行环境兼容。
Linux
/opt/emby-server/bin/ffprobe部分安装也位于 /usr/lib/emby-server/bin/ffprobe，以 Emby 实际返回为准。
macOS
解压安装：EmbyServer 解压目录/ffprobeApp 安装版请从 Emby 获取实际路径，或在应用包中查找自带的 ffprobe。

IP 和 API key 可以读取服务器配置；远程主机或容器中的文件仍需在本工具所在环境可访问。不要填成本工具自身的路径，也不要使用另行下载的通用 ffprobe 替代 Emby 版本。

统计和补全如何工作

按 Emby 媒体库分别统计电影中的 BDMV 文件夹和 Blu-ray ISO，包含 UHD 和 1080p；上方卡片为全部媒体库的去重总计。勾选媒体库后，下方影片明细和补全计划只包含所选范围。同一电影出现在多个库时只提交一次，各库数量不一定能直接相加。

检查内部音轨、字幕语言，以及每个原盘版本的时长，外部字幕不计入。历史数据不能证明“从未探测”，因此按当前保存的信息是否完整分类。信息不足的文件夹原盘和 ISO 都会加入补全计划。

将随附的 EmbyBlurayHelper.Plugin.dll 0.1.2 放入 Emby 的 plugins 目录并重启 Emby，可直接探测 BDMV 和 ISO，保存媒体轨道、语言和时长，不刷新标题、简介或图片。未更新 DLL 时，BDMV 保留原来的元数据刷新流程，提交后的核验窗口最多 15 秒。插件直接探测完成后立即核验；实际读取另有超时限制。

各平台复用按需 M2TS 读取，ISO 使用内置 UDF 解析；由 Emby 原版 ffprobe 识别真实编码，不依赖蓝光输入协议，无需挂载、整盘解压或转码。按主播放列表和轨道 PID 补全语言，过滤反复播放短片的菜单；导航损坏但仅有一个 M2TS 时读取该文件。原盘未标注或明确写 und 的语言保留为未识别，不根据片名猜测。

升级后重新检查电影库，旧读取器曾核验的 ISO 会列为待重新核验。启动补全才会重读正片轨道和时长，修正选错菜单的旧数据，保留外部字幕；成功后不会反复修复。核验媒体源和已保存结果后才计入成功。

检查结果是上次检查或核验时的快照。任务期间切换页面或关闭浏览器仍会继续；停止任务会停止后续提交和等待，已交给 Emby 的当前探测可能继续。重启工具后可继续补全，会先核对最新结果。详细过程记录在「运行日志」的 LibraryLanguage 模块。

工作方式与验证情况

目录和章节在内存中组织，视频、音频、字幕直接从原文件按 HTTP Range 读取，不预先生成 ISO 文件，不转码、不 remux。章节时间点来自 Emby；MPLS 不承载自定义章节名称和截图。

每部原盘只在首次同步时读取一次导航文件，结果保存在本工具数据目录；之后的媒体库同步不访问媒体硬盘，只有 Emby 重新扫描发现变化或实际播放时才更新。

开启后，符合条件的 BDMV 改走虚拟 ISO，不再经过 UHD 语言补写和多片段兼容；音轨、字幕语言由 Infuse 从 ISO 内的 MPLS / CLPI 读取。

工作方式与使用要求

仅处理 Infuse 静态播放的多片段 4K 蓝光原盘，并在 Emby 返回 404 / 500、能唯一匹配播放列表时介入。内置读取器用 MPLS 和 CLPI 确认片段完整、顺序与连接方式后，按需读取原始字节，不依赖 FFmpeg 的蓝光协议，不预先生成整部电影，不写临时视频文件。

本工具必须能读取完整原盘。目前支持未加密、单角度、单时间域的完整片段，后续片段须无缝连接；含裁剪、多角度或复杂时间域的标题暂不兼容。无法安全读取时保留原响应，日志会记录具体原因。其他播放器和 HLS 继续使用原有方式；开启此功能不会修改 Emby 的探测器。

本开关与「Infuse UHD 语言补写」独立。需要同时显示语言时，请一并开启语言补写。开启状态表示功能已允许介入，具体影片是否触发可在运行日志中查看。

Emby 显示原始轨道标题

显示补充的 Atmos、杜比视界规格备注。此项是 Emby 的全局显示设置，也会使用其他影片原有的音轨、视频和字幕标题；不改变编码或声道。

识别方式

TrueHD / E-AC-3 音轨需要读到 Atmos 标记才会补全；双层杜比视界需要验证基础层、增强层以及真实 RPU 元数据。不会根据文件名、4K 分辨率或音轨顺序猜测。

只读取所选正片的小段数据，结果缓存并保存到 Emby。增强探测超时或失败时保留原版结果。自动入库与详细探测记录可在 Emby 日志中查看，手动核验也记录到本工具日志。关闭功能不会清理已保存信息。

按媒体库补全规格

仅处理 BDMV 文件夹和 Blu-ray ISO，保留原有语言、时长及自定义备注。

计划、结果和继续处理

按媒体库检查电影中的 BDMV、Blu-ray ISO，包含 UHD 和 1080p。一个电影有多个版本时，仅处理其中的原盘媒体源。首次批量检查可能再次核验之前手动或自动处理过的影片，不根据是否已有 DV / Atmos 判断是否完成。

默认仅处理尚无有效批量核验记录的原盘；无新增规格的正常结果也会保存，避免每次重复处理。增强探测失败或保存核验失败不计为完成。勾选「重新核验已完成」可重新处理选定媒体库；引擎更新或保存的媒体信息变化后，重新检查会建立新的待核验计划。

任务在后台逐源执行，切换页面或关闭浏览器仍会继续。可停止并继续未完成的部分；已提交给 Emby 的当前探测可能仍会保存。进度保存在工具数据目录，详细日志位于 MediaFeatureBatch。它不刷新影片标题、简介或图片。

只想处理一部影片？在「单片检查」输入影片 ID，可查看并单独识别、保存这部原盘的规格。
