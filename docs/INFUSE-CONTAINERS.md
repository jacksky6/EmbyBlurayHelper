# Infuse 原盘封装格式

在「Infuse 播放增强」选择「普通原盘封装格式」，选择后立即保存。
现有配置缺少此字段时默认为 ISO，不改变升级前的播放行为。

| 条件 | 播放路径 |
| --- | --- |
| 普通格式选择 ISO | 沿用现有原盘直读；BDMV 的虚拟 ISO 仍由「原盘章节」开关控制；真实 ISO 保持原样 |
| 普通格式选择 MKV | BDMV / Blu-ray ISO 按 HTTP Range 生成带索引的虚拟 MKV，复制音视频与字幕 |
| 启用 DV 兼容且为支持的 UHD P7 原盘 | 优先转换 P7→P8.1，并始终输出 MKV，与普通格式选项无关 |
| 其他客户端或普通 MKV / MP4 | 保持原有播放方式 |

MKV 是实验性选择。需要本机可读取原盘和可运行的 FFmpeg，时长、帧率
与轨道信息须已补齐；复制封装不需要 libdovi。没有重新编码，也不提前
生成整片文件。音视频原始包、字幕语言与 Emby 已保存的章节进入 MKV，
不会改变源文件或 Emby 数据库。保留原始文件/文件夹名与发布组后缀，
新增 `.EmbyBlurayHelper.Remux.mkv` 特征。

切换前退出影片；保存后强制退出 Infuse，再打开并同步媒体库，防止沿用
旧容器信息。开关立即生效，变更格式会取消旧的片段缓存与转换工作，
不应在播放中切换。旧的带签名 MKV URL 返回 410 或 409，不返回伪装的 ISO。

MKV 比 ISO 直读多 FFmpeg 封装、片段内存与启动开销。与 DV 转换共用
512 MiB 单会话 / 1024 MiB 全局缓存设置及单个工作器；普通封装不分配
RPU 转换工作区。不预读整片；跳转只生成目标附近的片段。

目前仅支持能够唯一匹配完整片段、单角度及单时钟域的原盘。无法建立
安全导航的复杂原盘保留原方式并记录原因；播放中封装失败则停止该流。
普通 P7 的 MKV 复制不会自行转换为 P8.1；需要另开杜比视界兼容。

2026-11-07 本机验证：1080p AVC ISO《青蛇》、UHD 双层 HEVC BDMV
《碧海蓝天》通过元数据、HEAD、首/中/尾 Range、权限、重叠请求、
相邻片段连续性及压缩包保真核验。《青蛇》片尾的过短片段并入前一段，
解决 DTS 缺少初始化参数的问题。原有《少数派报告》P8.1 路径通过回归。
新版普通 MKV 仍需用户在 Infuse/DSM 日常播放验证；服务端检查不能替代真机。
