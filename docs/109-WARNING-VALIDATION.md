Emby 日志中的另外几类错误与本轮补全不同：启动时的 503 是服务未就绪；Infuse 对已不存在的 31654 条目的 404 是旧条目请求；System/Logs/Files 的 Sequence contains no matching element 来自 Emby 日志服务。未据此修改播放代理或屏蔽 Emby 错误。
