# 原盘章节补全

## 用途与范围

独立功能，覆盖 UHD / 1080p 的 BDMV 文件夹及 Blu-ray ISO。读取原盘正片 MPLS 章节入口并保存到 Emby，修复没有章节或仅有每五分钟自动生成章节的情况。普通 MKV、MP4、单独 M2TS 和 DVD ISO 不参与。

只读取小型导航文件。ISO 通过 UDF 随机访问导航文件，不解压影片、不扫描完整视频、不调用增强或原版 ffprobe，也不转码或重新封装。与语言补全、Atmos / Dolby Vision 识别、Infuse 代理的开关和任务状态相互独立。

## 安装与使用

1. 更新 Helper；章节时间点需要 DSM `0.2.0-18`，章节截图需要 `0.2.0-19` 或更新的 SPK。
2. 将附带的 **EmbyBlurayHelper.Plugin 0.1.6** DLL 复制到 Emby 数据目录的 `plugins`，确保 Emby 用户可读，并重启 Emby。SPK 不会擅自覆盖 Emby 的插件目录。
3. 打开 Helper 左侧一级菜单「原盘章节」，开启「原盘章节补全」。同机读取器自动填写；DSM 是 `/var/packages/EmbyBlurayHelper/target/probe.sh`，Windows 是当前 `EmbyBlurayHelper.exe`。
4. 点击「检查媒体库」，查看每个库的原盘数、已补全、待补全与已有章节数。检查只读取 Emby 保存的数据，不重新探测影片。
5. 全选或勾选部分媒体库，点击「补全所选媒体库」。后台依次读取正片导航，写入后立即从 Emby 读回核验。任务记录可跨 Helper 重启保留，停止后可以继续。

开关开启后，新片在 Emby 元数据后处理阶段自动补全。已有影片可批量处理或在 Emby 中完整刷新单片元数据。播放时读取已保存的章节，不重复解析原盘。关闭开关不会删除章节。

## 保护规则

- 保留片头开始、片头结束、片尾开始及其他非普通章节标记。
- 仅替换空列表、匹配当前媒体库生成间隔且名称仍是默认值的章节，以及由本工具管理且内容未经修改的章节。
- 已有非等间隔章节、自定义名称或时间点默认保留。重新核验也不强制覆盖这些内容。
- 与原生时间点一致时，保留已有名称、图片引用。
- 多版本影片逐媒体源确认所有者，不能把一个版本的章节写入另一个版本。
- BDMV 优先按 Emby 已选正片片段总大小精确匹配，并核对时长（允许码流探测与 MPLS 的小幅偏差）；ISO 或无法按片段大小匹配时，要求时长相差不超过两秒。多个匹配列表章节不同、来源变化、时间点重复/无序/越界时跳过该片并记录错误。
- 不修改音视频流、音轨字幕语言、时长、标题简介、图片或原始媒体文件。

## 日志与章节截图

批量记录位于 Helper 的 `NativeChapters` 日志，包含影片 ID、格式、正片播放列表、章节数、时间点及耗时。自动入库记录位于 Emby 日志。持久任务文件为数据目录下 `native-chapter-task.json`，配置/核验记录保存在 Emby 插件配置中。

章节补全只补时间点，菜单中的图片文字和 DIY 章节命名不在范围内。

**Emby 4.10.2 原生缩略图任务会跳过 BDMV / ISO**，只有时间点仍不能生成截图。插件 0.1.6 增加原盘截图适配，是否提取、扫描时还是计划任务提取、章节标记还是固定间隔，全部读取 Emby 各媒体库原有设置；Helper 页面只读显示状态，不再增加独立截图开关或计划。

在 Emby 媒体库设置中选择「生成视频预览缩略图」模式，间隔选择「章节标记」即可按原生章节截图。选择计划任务模式时，仍在 Emby 原有视频预览缩略图提取任务中设置时间；该任务成功完成后，自动排队「原盘章节截图（跟随 Emby）」显示原盘补充进度，可停止，无默认独立触发器。设为「从不」则不再提取，已有图片保留。详情、HDR / 杜比视界颜色与平台限制见 [原盘章节截图](DISC-THUMBNAILS.md)。

## 平台与结构

`ProbeWrapper/DiscChapterReader.cs` 复用现有 BDInfo / DiscUtils UDF 导航读取，统一 Windows、Linux、DSM 的读取路线。Helper 以 `--helper-chapters <原盘路径>` 提供仅导航的 JSON 子进程协议。Emby 插件在 Emby 账号下启动读取器，不需要访问 Helper 的账号、API key 或私有数据目录。容器需映射可执行文件和媒体路径，并满足对应架构/运行库条件。

插件 `Chapters/` 负责来源验证、合并、保存、自动元数据提供器；App `Chapters/` 负责认证后的配置和批量任务；Web `chapters.js` 独立处理界面。只在进入页面、修改配置、手动刷新，以及任务运行且页面可见时读取状态。

## 本机验证（2026-11-01）

Windows Emby 4.10.2.0：13 部 BDMV 和 2 部 ISO 均保存原生章节并读回核验。全库 31 部电影的原有时长、标题及媒体流字段在章节批量前后保持一致。普通文件未进入任务。

代表样本：《布达佩斯大饭店》18 章，《奇异博士 2》29 章，《禁闭岛》ISO 20 章，《青蛇》ISO 20 章。《布达佩斯大饭店》分别完整刷新、默认刷新后保留 18 章，《禁闭岛》ISO 完整刷新后保留 20 章；均等待 `RefreshItem Complete` 后重新读取确认，覆盖 Emby 最终提交阶段。

两个原盘的 ffprobe 码流时长与 MPLS 有约 2–8 秒差异；使用 Emby 保存的正片片段总大小精确确认后通过核验，未为通过测试而放宽为任意最长标题。NAS 109 的旧自动章节实际名称为「章节 1、章节 2……」，已覆盖默认中文名称的识别测试。NAS 此轮只读检查，未升级或重启。

Linux x64 在 WSL 中以独立非特权用户运行章节子进程，验证 18 个时间点、无需访问管理私有配置或原版 ffprobe，以及时长不匹配时拒绝写入。DSM 套件仍需真实 NAS 升级后的最终验证；WSL 套件生命周期和跨用户检查不能替代 DSM 真机测试。
